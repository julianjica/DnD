
## Audio (DungeonHarness presentation)

All files live in `public/assets/audio/` and are used by `lib/audio/ambience.ts`. Every file is **CC0 1.0** (public domain dedication, https://creativecommons.org/publicdomain/zero/1.0/), checked on each OpenGameArt page's license field. Files were copied unmodified (only renamed). Anything not listed here is synthesized at runtime with Web Audio (wind, rain, fire crackle, drips, drones, pads, choir, heartbeat, drums, crowd murmur, thunder, birds, owl, crickets, surf, ship creaks, and fallback versions of every SFX).

## Maps, tokens and world map (DungeonHarness maps)

All map terrain (stone, wood, grass, water, lava, roofs, trees, props, lighting, fog, parchment world map) is **drawn procedurally at runtime** with Canvas 2D / PixiJS in `components/map/` — no image files. The only third-party art is the token silhouette set below.

## Scene art, portraits and dice (DungeonHarness presentation)

No external image, model or font files are used. Everything is generated in code:

- `components/art/SceneArt.tsx` + `components/art/scene/*`: procedural SVG scenes (gradients, seeded noise ridges, shapes, SVG filters). Original code, no third-party art.
- `components/art/Portrait.tsx` + `lib/art/portrait.ts`: procedural layered SVG portraits. Original code.
- `components/dice/*`: dice meshes built from vertex tables at runtime and textured with canvas-drawn numbers (system serif font). Uses the npm packages `three` (MIT) and `cannon-es` (MIT); no bundled assets.
